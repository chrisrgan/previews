# Previews

A single-page, personalized preview of data and AI use cases, built for specific teams and industries.

## How it works

The page is one static file (`index.html`) served by GitHub Pages. It changes based on URL parameters:

| Parameter | What it does | Example |
|---|---|---|
| `c` | Company name shown in the header |
| `i` | Industry  |
| `r` | Role |
| `u` | Up to 4 specific use case cards, in order |


## Notes

- All data shown on the page is sample data for illustration only.
- No tracking, cookies or external resources. Everything runs in the browser.
